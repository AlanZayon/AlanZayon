## About

I'm a **Full-Stack .NET Developer** focused on **C#, .NET 8/9, and ASP.NET Core**, shipping REST APIs and Angular/Vue interfaces for event platforms, access control, and fiscal products.

I work end-to-end: business rules, multi-tenant isolation, background jobs, messaging, and integrations — including idempotent webhooks and DAS/DARF/OFX reconciliation.

**Right now I'm working on**
- Facial-biometrics event platforms (Angular 19, .NET 9, SQL Server, Azure Service Bus)
- Fiscal products in production (Vue 3, .NET 8, Hangfire, PostgreSQL, Redis, AWS S3)

**Looking for** Full-Stack .NET / C# roles where I own the API, the operations UI, and flow reliability.

## Featured projects

### [GameScore](https://github.com/AlanZayon/GameScore-Project)
Discover and rate games by player recommendations.

- **Stack:** Next.js · NestJS · TypeScript · PostgreSQL · Redis · BullMQ · Docker  
- Wilson-score ranking, full-text search, JWT + refresh, review-bomb detection  

### [Smart RPG Campaign Generator](https://github.com/AlanZayon/python-gerador-inteligente-RPG)
Turns a rules PDF into a playable campaign (overview, sessions, appendix).

- **Stack:** Python · Flask · Redis · PostgreSQL · AWS S3 · FAISS (RAG) · JWT  
- Async worker pipeline with job idempotency and Markdown published to S3  

### [ApiPdfCsv — Fiscal reconciliation (.NET 8)](https://github.com/AlanZayon/ApiPdfCsv)
DAS/DARF PDF + OFX → Domínio-standard CSV for accounting workflows.

- **Stack:** .NET 8 · C# · PostgreSQL · Vue (client: [front-pdf-to-excel](https://github.com/AlanZayon/front-pdf-to-excel))  
- **Live:** [front-pdf-to-excel.vercel.app](https://front-pdf-to-excel.vercel.app/) · [pdftoexcel.netlify.app](https://pdftoexcel.netlify.app/)  

### [Municipal staffing API](https://github.com/AlanZayon/api-maranguape)
Org structure and staffing for up to **10,000** public servants.

- **Stack:** Node.js · TypeScript · MongoDB · Redis · AWS S3 · React UI  
- **Live UI:** [interface-sistema-maranguape.vercel.app](https://interface-sistema-maranguape.vercel.app/)
